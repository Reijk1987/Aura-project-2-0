# AURA 2.0

Autonomous AI Engineering System.

## Architecture

AURA 2.0 is designed as a modular autonomous AI-engineering platform.

Core hierarchy:

User
  ↓
  AURA Core
    ↓
    Orchestrator
      ↓
      Specialized Agents
        ↓
        Capabilities / Memory / Execution
          ↓
          Verification / Audit
          
          ## Safety principles
          
          - Human authority remains highest.
          - Autonomous execution is disabled by default.
          - Actions require authorization.
          - Risk is evaluated before execution.
          - Important actions are verified.
          - Actions and decisions are auditable.
          - Failed operations must be recoverable.
